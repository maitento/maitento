# 00 · Connect

Checks that your API key works: prints who it belongs to and which models you can use. Used by
[Get started](../../docs/get-started/2-api-key.md).

```bash
cd typescript
npm install
node whoami.ts
```

```bash
cd python
pip install -r requirements.txt
python whoami.py
```

```bash
cd csharp
dotnet run whoami.cs
```
